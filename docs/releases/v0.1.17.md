Windows downloads are now available. You do not need Node.js, npm, or build tools.

## Downloads

- **Choicer-Voicer-Creator-0.1.17-windows-x64-setup.exe**: installation wizard with Start menu shortcut and uninstaller.
- **Choicer-Voicer-Creator-0.1.17-windows-x64.zip**: extract the entire archive and run **Choicer Voicer Creator.exe**. Keep the included files together.
- **SHA256SUMS.txt**: SHA-256 hashes for both downloads.

These builds target **Windows 10/11, 64-bit Intel/AMD**. Use the files above; GitHub's automatically generated **Source code** archives are for developers.

## Setup

Install [FFmpeg and FFprobe for Windows](https://ffmpeg.org/download.html#build-windows), then add their `bin` folder to PATH or set both executable paths in **Settings & usage**. The build needs `libtheora`, `libvorbis`, `libx264`, and `ffv1` encoders. The command-line tools are not bundled.

ElevenLabs is optional: manual editing and export work without a key. Movies and game files are not included.

## Included features

- Import MP4, MKV, MOV, AVI, WebM, and other common video containers.
- Trim scenes using video, waveforms, and timeline pictures.
- Edit, merge, duplicate, and retime dialogue; rename characters in bulk.
- Optional ElevenLabs captions and two-stem separation with subscription-based estimates.
- Export individual scenes or combine a collection into one Choicer Voicer Dub Pack.
- Copy collection descriptions for Reddit, Discord, and GameBanana.

## Updating and limitations

Save your project and close the editor before updating. Install the new setup EXE, or extract a new ZIP into a separate folder. The app does not automatically update. The ZIP version uses your Windows AppData profile for settings and caches, just like an installed copy.

This release is unsigned, so Windows may show an unknown-publisher warning. In-game playback and actual paid ElevenLabs requests have not been verified by automated tests. See the [guide and compatibility notes](https://github.com/Ugleh/Choicer-Voicer-Creator#readme).
