## Changes

- Separate only a selected problem area of an existing backing track. Choose the original scene audio for a fresh attempt, or the current backing to remove leftover voices. The surrounding audio is preserved, with short blends inside the selected edges. Undo restores the previous backing.
- Add imported audio or ElevenLabs-generated sound effects to a new scene timeline track. Move and trim clips, adjust source in points, set individual volume, add fades, mute, or remove them.
- Preview effects with the scene and include them in individual/collection backing WAV exports. Scene trimming keeps their timing aligned. Projects retain separate editable effects.
- Generate one prompted sound effect of 0.5–30 seconds. The confirmation shows an estimate; settings support a sound-effects rate and transaction history records requests. ElevenLabs is optional for imported effects.
- Includes v0.1.18's clearer backing import and silent-background buttons.

## Windows downloads

- **Choicer-Voicer-Creator-0.1.19-windows-x64-setup.exe**: installation wizard.
- **Choicer-Voicer-Creator-0.1.19-windows-x64.zip**: extract all files and run **Choicer Voicer Creator.exe**.
- **SHA256SUMS.txt**: hashes for both downloads.

Save your project and close the editor before updating. No Node.js or build tools are needed. [FFmpeg and FFprobe](https://ffmpeg.org/download.html#build-windows) remain separate prerequisites. Builds are unsigned, so Windows may show an unknown-publisher warning.

Cloud adapters are verified using simulated responses, without paid API calls. Listen to generated audio before exporting: re-separation can still leave voices or alter effects. Added effects are mixed into the backing WAV, not the original video audio or dialogue samples. Projects reference cached effect audio; keep that cache available with the project.
