## Windows downloads

- **Choicer-Voicer-Creator-0.1.18-windows-x64-setup.exe**: run the installation wizard.
- **Choicer-Voicer-Creator-0.1.18-windows-x64.zip**: extract the entire archive and run **Choicer Voicer Creator.exe**.
- **SHA256SUMS.txt**: checksums for both downloads.

Save your project and close the editor before updating. No Node.js or build tools are needed. [FFmpeg and FFprobe](https://ffmpeg.org/download.html#build-windows) remain separate prerequisites. ElevenLabs is optional. Builds are unsigned, so Windows may show an unknown-publisher warning.
