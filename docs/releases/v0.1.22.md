## Changes

- Keep sound effects editable with standard Copy, Cut, Paste, Delete, and Backspace shortcuts when an effect is selected.
- Add a sound-effect context menu to both the effect list and the scene timeline. Copy and cut retain the full clip, including its source offset, gain, fades, and mute state; paste places a new copy at the current playhead without changing the playhead.
- Keep sound-effect volume, fades, timing, and source offsets in the copied clip so duplicated effects can be adjusted independently.
- Make backing-track export compatible with FFmpeg builds that do not support `-filter_complex_script` by falling back to an inline filter graph. Modern builds continue to use the temporary filter script to avoid command-line length limits.
