## Changes

- Start a new project or open another video without restarting the editor. Choose Save & continue, Start new collection without saving, or Keep editing. Cancelling the save or video picker keeps the current project.
- Add an always-visible File, Edit, View, and Help menu bar. File includes project/video opening, Save/Save As, exports, settings, and Exit. Edit includes Undo/Redo, clipboard actions, Delete, and Select All. View controls preview pinning, dialogue overlays, and full screen.
- New Project uses Ctrl+N, Open Project uses Ctrl+O, and Open Video uses Ctrl+Shift+O. New collections start with a fresh save path and Undo history.

## Windows downloads

- **Choicer-Voicer-Creator-0.1.23-windows-x64-setup.exe**: installation wizard.
- **Choicer-Voicer-Creator-0.1.23-windows-x64.zip**: extract and run **Choicer Voicer Creator.exe**.
- **SHA256SUMS.txt**: download hashes.

Save your project and close the editor before updating. FFmpeg and FFprobe remain separate prerequisites. Builds are unsigned.
