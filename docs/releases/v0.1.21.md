## Changes

- Generate four ElevenLabs sound-effect choices, each with its own solo Play button. Check one or more choices and import them together; generation does not automatically add sounds to the scene.
- Show the combined estimate for four generations and record each API request separately. Completed choices remain available if a later request fails or is cancelled. No automatic retries.
- Move dialogue and sound-effect clips without moving the playhead. Clip edges snap to the playhead when dragged close, from either direction. Resizing also preserves the playhead. Each drag has its own Undo step.
- Includes v0.1.20's preview layout and pinning, compact optional effects, Save As, and scene context menu with collection-export exclusions.
