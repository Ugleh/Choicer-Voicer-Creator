# Validation

Validated on Windows 10 using FFmpeg 2023-03-02 and Node 24.19.0. Electron 44.4.5 is bundled in the packaged app.

- Thirty-two unit tests cover INI escaping and timing, Windows-safe names, backing validation, dialogue limits, transcription grouping, representative ElevenLabs success/failure responses, copied executable paths, FFmpeg progress parsing, locked selection boundaries, bulk character assignment, line merging, equal start timestamps, scene-wide preview captions, preview bounds, timecode parsing, and scene trim planning.
- FFmpeg integration generates both MP4 and MKV inputs, builds previews/waveforms/thumbnails, and exports a pack with a nonzero scene offset. It checks Theora video, PCM dialogue encoding, duration, metadata, and refusal to replace an existing output.
- Electron desktop automation exercises native MKV import, video/audio playback, scene selection, caption and character editing, backing import/audition/review, save/reopen, scene removal/undo, and export.
- The packaged Windows EXE is separately checked for startup, its isolated desktop bridge, settings, and tool discovery.
- The production build passes. The dependency audit reported zero known vulnerabilities after updating Electron and the ZIP reader.

No live paid ElevenLabs requests were submitted and no installed Choicer Voicer game was available. Provider quality, account permissions, actual pricing, and in-game playback remain manual acceptance checks.

The export filter chain bounds audio before normalization, rebuilds timestamps afterward, and fixes its final duration by sample count. Every exported dialogue WAV is probed before the pack folder is finalized. Earlier tests covered only a subset of the loudness filter's timing behavior; version 0.1.9 adds a regression that compares the complete normalized audio samples.
