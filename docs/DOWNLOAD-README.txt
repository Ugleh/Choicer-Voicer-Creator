CHOICER VOICER CREATOR - WINDOWS x64

No Node.js, npm, or build tools are needed to use this download.

Installer: Run the setup EXE and follow the installation wizard.
ZIP: Extract the entire ZIP, then run "Choicer Voicer Creator.exe".
Keep the EXE together with all the included folders and files.

FFMPEG SETUP
Install a Windows FFmpeg build containing ffmpeg.exe and ffprobe.exe:
https://ffmpeg.org/download.html#build-windows
The build must include libtheora, libvorbis, libx264, and ffv1 encoders.
Add its bin folder to PATH or choose both executable paths in the app's
Settings & usage panel. FFmpeg/FFprobe command-line tools are not bundled.
The included ffmpeg.dll belongs to Electron and does not replace them.

GET STARTED
Drop a video into the app, create scenes, and add dialogue lines.
ElevenLabs is optional. Manual editing and export work without an API key.
Projects reference the source movie and generated audio; keep those files.
Settings and caches are stored under your Windows AppData profile, even
when running the ZIP version. The ZIP does not isolate app settings.

UPDATES
Save your project and close the app before installing a new version.
For ZIP updates, extract the new version into its own folder.
There is no automatic updater. Download new versions from:
https://github.com/Ugleh/Choicer-Voicer-Creator/releases

This build is unsigned; Windows may display an unknown-publisher warning.
